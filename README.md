# 🌻 Landing Page — Psico Aline Alves

Landing Page institucional desenvolvida para a psicóloga clínica Aline Alves, especialista em Gestalt-terapia e comportamento alimentar. O projeto foi criado para oferecer uma navegação leve, acolhedora e responsiva, permitindo que potenciais pacientes conheçam a abordagem terapêutica e agendem suas consultas de forma rápida. 

Originalmente construído com HTML, CSS e JavaScript Vanilla, **este projeto foi totalmente refatorado para React**, visando maior componentização, facilidade de manutenção e melhoria de performance.

🔗 **Website:** 

## Funcionalidades

* **Navegação Suave (Smooth Scroll):** Âncoras responsivas com ajuste dinâmico para navegação fluida entre seções.
* **Carrossel Interativo de Acompanhamentos:** Rolagem horizontal de especialidades controlada via botões, agora refatorada utilizando o hook `useRef` do React.
* **Integração com WhatsApp:**
  * Botões de chamada para ação (CTA) no header e banners.
  * Formulário de contato dinâmico (gerenciado via `useState`) que coleta e converte as respostas, direcionando o usuário para o WhatsApp com uma mensagem pré-formatada.
* **Design Responsivo (Mobile First / Adaptive):** Layout perfeitamente ajustado para desktops, tablets e smartphones (com media queries customizadas).
* **Botão "Voltar ao Topo":** Fixado na tela para facilitar a navegabilidade do usuário.

## 🚀 Tecnologias e Ferramentas

A nova arquitetura do projeto utiliza as seguintes tecnologias:

* **React.js:** Criação de interfaces baseadas em componentes funcionais e gerenciamento de estado/referências com Hooks (`useState`, `useRef`).
* **Vite:** Ferramenta de build para o ambiente de desenvolvimento.
* **CSS3:** Estilização customizada com suporte nativo a aninhamento (Nesting) e variáveis CSS.
* **Bootstrap 5:** Sistema de grid responsivo e componentes base de layout.
* **Google Fonts:** Tipografia *Poppins* para um visual limpo e moderno.
