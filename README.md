# Landing Page - Psicóloga Aline Alves 🌻

**Status:** 🟢 Online | **Acesse o site:** [alinealvespsicologia.com.br](https://alinealvespsicologia.com.br)

Uma landing page responsiva e otimizada para SEO, desenvolvida para apresentar os serviços de psicologia clínica e Gestalt-terapia. O projeto tem foco em performance, acessibilidade e em proporcionar um primeiro contato acolhedor e intuitivo para quem busca iniciar uma jornada terapêutica.

> **💡 Nota de Evolução do Projeto:** Inicialmente o site foi construído utilizando apenas HTML, CSS e JavaScript puro, o projeto foi totalmente refatorado e migrado para **React**. Essa transição garantiu maior organização do código, componentes reutilizáveis e uma base muito mais sólida para futuras atualizações.

## Tecnologias Utilizadas

* **[React](https://reactjs.org/)**: Biblioteca JavaScript para construção da interface de usuário baseada em componentes.
* **[Vite](https://vitejs.dev/)**: Ferramenta de build para o ambiente de desenvolvimento.
* **[Bootstrap 5](https://getbootstrap.com/)**: Framework CSS utilizado para o sistema de grid, alinhamentos e componentes responsivos.
* **CSS3 Customizado**: Estilização adicional utilizando variáveis CSS (Design Tokens) e media queries precisas para adaptação fluida entre mobile, tablet e desktop.

## Funcionalidades e Destaques

* **Design Responsivo (Mobile-First):** Layout adaptável para smartphones, tablets e desktops.
* **Header Inteligente:** Barra de navegação fixa com ajuste dinâmico de container, garantindo alinhamento com o restante do site.
* **Otimização de SEO Avançada:** 
  * Tags HTML semânticas e hierarquia correta de títulos (`<h1>`, `<h2>`).
  * Meta tags de descrição e palavras-chave.
  * Open Graph (OG) configurado para gerar cards atraentes em compartilhamentos no WhatsApp e redes sociais.
* **Performance:** Arquitetura estática leve garantindo carregamento instantâneo.
